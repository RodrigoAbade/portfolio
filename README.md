# Portfólio — Rodrigo Abade

Site profissional de **Rodrigo Abade**, desenvolvedor de software com foco em **Backend C# / .NET**. Apresenta experiência, tecnologias, projetos, publicações e contatos.

**Site:** https://rodrigo-abade.vercel.app

## Tecnologias

- HTML5
- CSS3
- JavaScript (sem framework)

## Executar localmente

Abra `index.html` no navegador ou use um servidor HTTP estático na pasta do projeto:

```bash
python -m http.server 8000
```

Acesse http://localhost:8000.

## Estrutura

```text
index.html      # Conteúdo e estrutura da página
style.css       # Estilos e layout responsivo
script.js       # Interações e traduções
perfil.jpeg     # Foto do perfil
Curriculo_Rodrigo_Abade_Nunes_Final.pdf  # Currículo para download
```

## Publicação

O site é estático e pode ser publicado na Vercel. Ao reorganizar os arquivos, atualize os caminhos referenciados no HTML e a configuração de deploy, se necessário.
